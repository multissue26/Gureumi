# 띵타 개인DB v0.7.0 — 페이지

## v0.7.0 변경점

- 기존 `원본 DB 탐색` 메뉴를 제거하고 `초뉴비 가이드`로 교체
- 메인인 `요리 / 채집 / 내 농장 / 예상 수익` 흐름은 유지하고, 나머지 서버 정보는 초뉴비가 질문형으로 찾는 백과로 통합
- 현재 검색 인덱스 **1,511개 고유 항목**
  - 공식 위키 아이템 정보 분류: 일반 / 야생 / 뱃지 / 세레니티 / 루미디아 / 파라다이스
  - 공식 랜덤 박스·캡슐·보급품·기타 확률표
  - 공식 상점 데이터 **422개 거래 행 / 399개 고유 아이템명 전부 연결**
  - 기존 사이트 음식·황금 음식·요리 재료·농작물 전부 연결
  - 노크틸라 장비·강화·스킬·룬·좌표 스크롤 등 최신 전투/편의 문서 추가
- 자연어 질문형 검색 지원
  - `세이지 곡괭이 강화하려면?`
  - `하급 라이프스톤 어디서 구해?`
  - `카르세나의 룬이 뭐야?`
  - `루트바인 스태프 강화`
  - `좌표 스크롤 어디서 사?`
  - `중급 라이프스톤 재료`
- 아이템 상세에 `이게 뭔지 / 어디서 구하는지 / 어디에 쓰는지 / 제작 재료 / 상점 가격 / NPC / 장소 / 관련 아이템 / 공식 출처` 표시
- 공식 상점에 등장하는 아이템은 구매·판매·교환 값과 지역·장소·NPC를 표로 연결
- 재료 칩에 마우스를 올리면 획득처·사용처·레시피 미리보기, 클릭하면 그 재료의 상세로 계속 추적
- 세이지 곡괭이 강화 전용 상세 가이드
  - 세레니티 NPC 로니 이용 절차
  - 1~15강 하급/중급/상급 라이프스톤, 골드, 루비, 성공률 전체 표
  - +1~3 하급만 / +4~5 중급 추가 / +6 상급 추가 / +7 루비 추가
  - **하급 라이프스톤은 3강 이후에도 계속 같이 들어간다는 주의문**
  - 선택한 목표 강화까지 최소 골드·강화석·루비 자동 합산
  - 공식 성공률을 이용한 단순 확률 기대 골드 참고값(가정 명시)
  - 라이프스톤 제작 재료 및 하위 원재료 자동 환산
  - 세이지 곡괭이 1~15강 성능표
- 노크틸라 무기 강화 전용 상세 가이드
  - 브론 `1번 → 장비 강화하기`
  - 루트바인 스태프 / 템페스트 해머 / 아크 블래스터 / 레디언트 윙보우 / 글레이셜 스피어 / 인페르널 클레이모어 / 팬텀 사이드 선택
  - 등급별 +1~+15 정확한 골드·재료·성공률 표
  - 목표 강화까지 총 골드와 총 재료 자동 합산
  - +3/+6/+9/+12 스킬 슬롯 조건과 스킬 시스템 안내
- 노크틸라 장신구 강화 상세 가이드
  - 카르벤 / 세리온 / 브렉사 / 오브레 단계별 +1~+5 골드·수호석·성공률·확정 시도 횟수
  - 다음 등급 승급 성공률/확정 횟수와 어빌리티 스톤 요구량 표시
- 노크틸라 스킬 35종을 무기별로 편입하고, 각 스킬의 무기 강화 선행 조건·능력 개방의 문장 개수·해금 골드·각성석 종류 연결
- 룬 20종 × 4등급(총 80개)의 정확한 효과 수치, 최대 3개 장착, 동종 중첩, 제거 시 소멸 주의사항 반영
- 좌표 스크롤의 세라/루아 구매 비용, 거래 가능 여부, 저장/이동 조작, 1분 공용 쿨타임, 이름/설명 명령어 제한 반영
- `카르세나의 룬`처럼 공식 문서에서 세부 소비 사용처가 확인되지 않는 항목은 추측하지 않고 확인 범위를 분리
- 설탕 큐브는 `사탕수수 ×64` 레시피 유지
- 페이지 전용 업데이트. 모드/Cloudflare Worker는 변경하지 않음

### 데이터 완전성 기준

`1,511개`는 2026-10-02 기준으로 **현재 공식 위키 아이템 정보·확률/강화/노크틸라 문서, 공식 상점 카탈로그, 기존 사이트 요리/채집 DB에서 이름을 확인할 수 있는 항목을 합치고 중복 제거한 값**입니다. 공식 문서에 아직 등재되지 않은 비공개·미문서화·운영 중 임시 아이템은 사이트가 임의로 만들어 넣지 않습니다.

- 설탕 큐브 가공 재료를 `설탕 ×64`에서 실제 레시피인 `사탕수수 ×64`로 수정

## v0.6.1 변경점

- 예상 수익 상단의 큰 요약 카드 대신 `경작지 균형 추천` 표 추가
- 전체 경작지와 현재 설치 수를 기준으로 남은 칸을 자동 추천
  - 현재 0칸 / 전체 70칸이면 토마토 22 · 양파 30 · 마늘 18칸 추천
  - 이미 추천량보다 많이 설치한 작물은 추가 추천에서 자동 제외
  - 남은 칸은 현재 설치량을 고정한 채 평균 시간당 생산량이 가장 비슷해지도록 재배분
- `내 농장` 메뉴에 `지금 만들 수 있는 요리` 영역을 별도로 추가
- 준비도 100% 미만 음식은 `조금만 더 심으면 되는 요리`로 분리
- 음식 카드의 농장 준비도 바에 마우스를 올리면 부족한 작물 이름 표시
- 가격 상세의 과거 기록 날짜가 `undefined일`로 표시될 수 있던 문제 수정

## v0.6.0 변경점

- 사이드바에 `예상 수익` 메뉴 추가
- 현재 전체 경작지 / 토마토 / 양파 / 마늘 경작지 수 입력 및 브라우저 자동 저장
- 세레니티 핵심 작물의 구조화된 재배 데이터 추가
  - 토마토: 15분, 1~3개, 평균 2개
  - 양파: 15분, 1~2개, 평균 1.5개
  - 마늘: 15분, 1~4개, 평균 2.5개
- 작물별 15분 / 분당 / 시간당 생산량을 최소·평균·최대로 계산
- 15종 음식의 레시피를 재귀적으로 풀어 토마토·양파·마늘 실제 소모량 자동 계산
- 복합 음식은 평균 수율 기준 가장 부족한 작물을 자동 병목 처리
- 음식별 15분 / 분당 / 시간당 기대 제작량과 예상 수익 계산
- 예상 수익은 최소 / 평균 / 최대 수율 범위를 모두 표시
- `나의 판매가` / `시장 기준가` 전환 지원
- 평균·최소·최대 시간당 수익, 시간당 제작량, 이름순 정렬 지원
- 토마토 / 양파 / 마늘 / 복합 음식 필터 추가
- 알려진 NPC 구매비를 이용한 평균 시간당 순수익 참고값 추가
- 경작지 초과 배정 경고 및 미배정 칸 표시
- 기존 이미지 fallback 처리 오류도 함께 보완

### 예상 수익 계산 가정

예상 수익 메뉴는 토마토·양파·마늘 경작지가 생산 병목이라고 보고 계산합니다. 감자·호박·고기·과일·구매 재료 등 다른 재료는 충분히 확보되어 있고, 가공/조리 대기시간은 없다고 가정합니다.

수익 계산식은 다음과 같습니다.

`기간 기대 제작량 × 선택한 현재 판매가`

최소/최대 수익은 작물 드롭 수율 범위만 반영하며 판매가 변동 범위는 섞지 않습니다.

## 기존 가격 연동

- 사이트는 Cloudflare API에서 확정 가격을 읽습니다.
- 공식 요리 가격 변동 일정 기준 상태 표시:
  - 매월 1, 3, 6, 9, 12, 15, 18, 21, 24, 27, 30일 오전 3시
  - 기준 시간대: Asia/Seoul (KST)
- 사이트 사용자가 `최신 가격 업데이트`를 눌렀을 때만 Cloudflare candidate를 published로 확정
- 홈 차트는 Cloudflare에 확정된 가격 주기만 한 점씩 기록
