# 띵타 개인DB v0.3.2

## 이번 버전 핵심

### 1. 아이템 찾기 — 요리 밖의 상점 품목까지 통합 검색
- 공식 띵타이쿤 위키의 **스폰 상점 / 스폰 특수 상점 / 세레니티 상점가** 정보를 개인 DB용으로 정리했습니다.
- 현재 정적 스냅샷: **422개 거래 항목** (2026-09-30 확인)
- 검색 대상: 아이템명, NPC명, 지역, 상점/시설명, 분류, 가격/교환값
- 필터: **전체 / 내가 구매 / 내가 판매 / 교환**
- 검색 결과마다 `지역 → 상점/시설 → NPC`, 거래 방향, 가격/교환값, 공식 위키 원문 링크를 표시합니다.
- 예: `발광석` 검색 → `스폰 → 꽃잎 공방 → 바름 → 내가 구매 200 G`
- 상단 통합 검색에서 검색어를 입력하고 **Enter**를 누르면 바로 아이템 찾기로 이동합니다.

> 이 데이터는 사이트에 포함된 2026-09-30 기준 스냅샷입니다. 게임 패치 후 가격/품목이 달라질 수 있으므로 각 결과의 **공식 위키 원문** 링크를 함께 제공합니다.

### 2. 화면 설정 / 폰트 변경
- 기본 글꼴을 **Gmarket Sans**로 설정했습니다.
- 우측 상단 설정 버튼에서 다음 글꼴을 선택할 수 있습니다.
  - Gmarket Sans
  - Pretendard
  - System UI
  - Editorial serif (제목용 세리프 조합)
- 전체 UI 글자 크기도 슬라이더로 조절할 수 있습니다.
- 글꼴/글자 크기 선택은 `localStorage`에 저장되어 다음 실행에도 유지됩니다.
- Gmarket Sans는 PC에 설치된 로컬 글꼴을 우선 사용하고, 없으면 공개 웹폰트로 불러옵니다.

### 3. 기존 기능 유지
- 요리 15종 + 황금 요리
- 요리 상세 / 재료 수급 정보
- 내 농장 및 재배 체크
- 보유 작물 기반 제작 준비도
- `prices.json` 자동 연결/주기적 갱신
- 요리 수익 계산기
- 타이머
- 메모장
- 기존 ddingtasearch 참고 DB 탐색

### 4. Windows 모드 빌더
- Windows에서 현재 실행 가능한 `java.exe`를 확인합니다.
- `java -version`과 `sun.arch.data.model`로 Java 21 + 64비트를 검사합니다.
- Fabric Loom 1.10 요구사항에 맞춰 **Gradle 8.12.1**을 사용합니다.
- Gradle은 프로젝트 내부 `.gradle-local`에 한 번만 내려받고 이후 캐시를 재사용합니다.

# 띵타 개인DB v0.1

기존 ddingtasearch를 참고해 **PC/뉴비 우선**으로 다시 구성한 개인용 프로토타입입니다.

## 지금 들어간 기능

- 사이드 메뉴 기반 구조
- 요리 15종: COMMON / NORMAL / RARE / EPIC
- 일반/황금 음식 이미지 및 제작법
- 재료 이미지 + hover 수급 설명
- `내 농장` 체크리스트 (브라우저에 자동 저장)
- 현재 재배 작물 기준 요리 준비도
- 작물 하나를 더 심었을 때 추가로 농작물 조건이 완성되는 요리 수 추천
- 실제 NPC에게 지출하는 고정 구매재료 비용만 별도 계산
- `prices.json` 파일 연결 및 2초 간격 자동 재읽기
- 현재 판매가 / 나의 판매가 / 최근 가격 이력 표시

## 가격 파일 연결

가격 수집 모드가 생성할 기본 위치:

```text
.minecraft/config/dding-price-helper/prices.json
```

Chrome/Edge에서 사이트의 **가격 파일 연결**을 누르고 이 파일을 한 번 선택합니다.
브라우저가 권한을 유지하는 동안 같은 파일의 변경을 자동으로 다시 읽습니다.
브라우저가 권한을 다시 요구하는 경우 버튼을 한 번 눌러 재허용하면 됩니다.

가격 파일은 누적 로그가 아니라 현재 스냅샷을 덮어쓰므로 용량이 계속 커지지 않습니다.

## 로컬에서 사이트 열기

GitHub Pages에 올리기 전 간단히 확인하려면 Windows에서 `run-local-site.bat`을 실행하세요.
Python Launcher(`py`)가 설치되어 있으면 `http://127.0.0.1:8088`로 엽니다.

## 모드

`mod-source/`에 Minecraft Java 1.21.4 + Fabric용 소스가 있습니다.
이 프로토타입 모드는 정상적으로 열린 인벤토리 GUI에 **이미 동기화된 ItemStack 이름/Lore만 읽으며** 자동 클릭, 명령어, HTTP 업로드, 커스텀 서버 패킷을 구현하지 않았습니다.

GitHub에 올린 뒤 저장소 루트의 `.github/workflows/build-mod.yml`이 `mod-source/`를 자동 빌드하도록 들어 있습니다.
실사용 전에는 실제 가격 GUI에서 Lore가 예상 형식으로 들어오는지 1회 테스트가 필요합니다.

## 데이터 출처 구분

- 음식/황금 음식 이미지: 사용자가 업로드한 2026-09-23 띵타이쿤 리소스팩
- 현재 15종 요리 레시피/가격 범위/기본 수급 정보: 공식 띵타이쿤 위키

## v0.1.1 Windows 실행 파일

- 사이트 실행: `START-SITE.bat` 더블클릭
- 모드 JAR 빌드: `BUILD-MOD.bat` 더블클릭

- 첫 모드 빌드에서는 Gradle/Fabric/Minecraft 의존성을 인터넷에서 다운로드하므로 시간이 걸릴 수 있습니다. 이후에는 캐시를 재사용합니다.
- 기존 `dp0`, `rorlevel` 오류를 막기 위해 BAT 파일은 ASCII + Windows CRLF로 다시 작성했습니다.
