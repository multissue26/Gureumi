# 띵타 개인DB v0.6.0 — 페이지

## v0.6.0 변경점

- 사이드바에 `예상 수익` 메뉴 추가
- 현재 전체 경작지 / 토마토 / 양파 / 마늘 경작지 수 입력 및 브라우저 자동 저장
- 세레니티 핵심 작물의 구조화된 재배 데이터 추가
  - 토마토: 15분, 1~3개, 평균 2개
  - 양파: 15분, 1~2개, 평균 1.5개
  - 마늘: 15분, 1~4개, 평균 2.5개
- 작물별 15분 / 분당 / 시간당 생산량을 최소·평균·최대로 계산
- 15종 음식의 레시피를 재귀적으로 풀어 토마토·양파·마늘 실제 소모량 자동 계산
- 복합 음식은 평균 수율 기준 가장 부족한 작물을 자동 병목 처리
- 음식별 15분 / 분당 / 시간당 기대 제작량과 예상 수익 계산
- 예상 수익은 최소 / 평균 / 최대 수율 범위를 모두 표시
- `나의 판매가` / `시장 기준가` 전환 지원
- 평균·최소·최대 시간당 수익, 시간당 제작량, 이름순 정렬 지원
- 토마토 / 양파 / 마늘 / 복합 음식 필터 추가
- 알려진 NPC 구매비를 이용한 평균 시간당 순수익 참고값 추가
- 경작지 초과 배정 경고 및 미배정 칸 표시
- 기존 이미지 fallback 처리 오류도 함께 보완

### 예상 수익 계산 가정

예상 수익 메뉴는 토마토·양파·마늘 경작지가 생산 병목이라고 보고 계산합니다. 감자·호박·고기·과일·구매 재료 등 다른 재료는 충분히 확보되어 있고, 가공/조리 대기시간은 없다고 가정합니다.

수익 계산식은 다음과 같습니다.

`기간 기대 제작량 × 선택한 현재 판매가`

최소/최대 수익은 작물 드롭 수율 범위만 반영하며 판매가 변동 범위는 섞지 않습니다.

## 기존 가격 연동

- 사이트는 Cloudflare API에서 확정 가격을 읽습니다.
- 공식 요리 가격 변동 일정 기준 상태 표시:
  - 매월 1, 3, 6, 9, 12, 15, 18, 21, 24, 27, 30일 오전 3시
  - 기준 시간대: Asia/Seoul (KST)
- 사이트 사용자가 `최신 가격 업데이트`를 눌렀을 때만 Cloudflare candidate를 published로 확정
- 홈 차트는 Cloudflare에 확정된 가격 주기만 한 점씩 기록
